{{- $replicaFloor := include "leoflow.controlPlaneReplicaFloor" . | int }}
{{- if and (kindIs "bool" .Values.podDisruptionBudget.enabled) .Values.podDisruptionBudget.enabled (le $replicaFloor 1) }}

WARNING: podDisruptionBudget.enabled=true with a single replica. The budget
blocks EVERY voluntary eviction of the one control-plane pod: node drains hang
on it, cluster/node auto-upgrades stall (platforms that bound the wait override
it after a while), and the pod still dies to involuntary disruptions. Prefer
replicaCount > 1 — the PDB then turns itself on — or leave enabled unset (auto).
{{- end }}
{{- $logMounters := include "leoflow.logMounterCeiling" . | int }}
{{- if and (gt $logMounters 1) (not .Values.logs.persistence.enabled) (eq .Values.logs.sink.provider "disk") }}

WARNING: more than one control-plane pod (up to {{ $logMounters }}) with logs.persistence.enabled=false and logs.sink.provider=disk.
Each pod keeps task logs in its own emptyDir: a log written by the scheduler
leader is invisible to every other pod's API/UI, and every log is lost when a pod
restarts. Ship task logs to object storage (logs.sink.provider=s3|gcs with
logs.sink.bucket) or use a ReadWriteMany logs PVC — see
helm/leoflow/examples/values-ha.yaml.
{{- end }}

{{- $preStopSleep := int .Values.deployment.preStopSleepSeconds }}
{{- if and (gt $preStopSleep 0) (ne (include "leoflow.preStopSleepHookSupported" .) "true") }}

WARNING: deployment.preStopSleepSeconds={{ $preStopSleep }} is set, but this apiserver ({{ .Capabilities.KubeVersion.Version }})
has no native preStop `sleep` action, so the chart rendered NO lifecycle hook and
the value has no effect. The action is gated on PodLifecycleSleepAction: beta and
on by default from Kubernetes 1.30, alpha and off in 1.29, absent before that.
The hook is omitted rather than rendered because an apiserver without the action
REJECTS the empty `preStop: {}` it is left with, which would fail this install
instead of dropping the sleep. So the install works and keeps the pre-hook
behavior: a terminating replica goes on accepting NEW agent log streams for the
endpoint-propagation window, and each one creates an empty log object for an
attempt whose lines then land nowhere. Move the control plane to 1.30+ to get the
sleep, or set deployment.preStopSleepSeconds=0 to stop asking for it.
{{- end }}
