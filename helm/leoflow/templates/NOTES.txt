Leoflow control plane "{{ include "leoflow.fullname" . }}" is installing into namespace "{{ .Release.Namespace }}".

1. Task pods are created in namespace "{{ .Values.taskNamespace }}". Ensure it exists:
     kubectl create namespace {{ .Values.taskNamespace }} --dry-run=client -o yaml | kubectl apply -f -

2. Agents in task pods dial the control plane gRPC at:
     {{ include "leoflow.agentControlPlaneAddr" . }}

3. Reach the API:
{{- if .Values.ingress.enabled }}
     via the configured Ingress host(s).
{{- else }}
     kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "leoflow.roleName" (dict "ctx" . "role" (ternary "api" "all" .Values.split.enabled)) }} {{ .Values.ports.http }}:{{ .Values.ports.http }}
     # then open http://localhost:{{ .Values.ports.http }}
{{- end }}
